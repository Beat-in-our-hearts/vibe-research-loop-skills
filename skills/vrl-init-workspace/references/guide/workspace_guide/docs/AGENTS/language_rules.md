# Language rules

- Think and write in English: reasoning, plans, analysis, and every file you write or modify, including code, comments, commit messages, documentation, and configuration.
- Reply to the user in Simplified Chinese, and write Notion pages in it too; keep in English what agents look up: the names of Notion databases, their properties and views, and the options of select and status properties.
- Never translate code, file paths, commands, identifiers, or technical terms.
