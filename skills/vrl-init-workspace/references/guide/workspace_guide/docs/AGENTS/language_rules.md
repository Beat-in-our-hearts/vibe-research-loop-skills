# Language rules

- Think and edit in English: reasoning, planning, and analysis, and every file you write or modify, including code, comments, commit messages, documentation, and configuration.
- Reply to the user in Simplified Chinese: explanations, summaries, questions, and status updates.
- Write Notion pages in Simplified Chinese as well, since the user reads them; keep the names of the Notion databases, their properties and views, and the options of their select and status properties in English, as agents look them up.
- Keep code, file paths, commands, identifiers, and technical terms as they are; never translate them.
